# Changelog

## 1.3.1-beta — 2026-10-10

Изменения по замечаниям модерации Blender Extensions; поведение синхронизации не меняется.

- Без потоков: модули `threading` и `queue` больше не используются. HTTP-сервер обрабатывает
  запросы прямо в таймере Blender (неблокирующий `select`), а меши и текстуры с Roblox качаются
  в отдельных процессах (`subprocess` + `fetch_asset.py`), Blender их не ждёт.
- Плагин Roblox Studio больше не упаковывается в zip расширения: ставится из Creator Store
  или как `RobloxLiveLink.lua` из релиза на GitHub.
- Все комментарии в коде плагина переведены на английский.

## 1.3.0-beta — 2026-10-10

> ⚠️ **Бета-версия.** Аддон ещё тестируется: возможны ошибки, а поведение может измениться
> в следующих версиях. Не используйте его как единственную копию сцены и сохраняйте плейс
> и `.blend` перед работой.

### Формат: Blender Extension
- Аддон стал расширением Blender (`blender_manifest.toml`, Blender 4.2+), установка через
  **Get Extensions → Install from Disk** или перетаскиванием zip. Отдельные сборки под Windows,
  macOS Apple Silicon и macOS Intel.
- Pillow поставляется внутри расширения, ставить его вручную больше не нужно.
- Скачанные текстуры и меши хранятся в пользовательской папке расширения, а не рядом с кодом.
  Кэш старой версии переносится автоматически при первом включении.
- Загрузки из интернета выполняются только при включённом **Allow Online Access**.
- Лицензия: GPL-3.0-or-later.

### Импорт текстур (переработан)
- Все Decal, Texture и SurfaceGui детали переносятся на свои грани. Раньше переносилась только одна
  текстура на деталь, и она растягивалась на весь блок.
- SurfaceGui рисуется целиком: Frame, TextLabel, ImageLabel, UIStroke, UICorner, TextScaled, перенос
  строк, ImageRect (спрайт-листы). Шрифты берутся из установленной Roblox Studio, Gotham заменяется
  на Montserrat. Для кириллицы подбирается шрифт, в котором она есть.
- Надписи и декали работают и на деталях внутри объединённых моделей.
- Texture тайлится по StudsPerTile и Offset на своей грани.
- MaterialVariant передаётся и для деталей внутри моделей. Поддерживаются переопределения
  материалов в MaterialService, тайлинг по StudsPerTile и карта Metalness.
- **Процедурные материалы.** Рисунок встроенных материалов Roblox (кирпич, дерево, доски, плитка,
  булыжник, трава, песок, бетон, камень, металл и др. — все материалы Roblox) строится узлами
  шейдера, без картинок. Цвет детали задаёт итоговый цвет, рельеф делает узел Bump. Пакет больше
  не содержит текстур (в том числе текстур Roblox) во избежание нарушения авторских прав и стал
  втрое меньше.
- Настройка **Match Roblox Colors**: преобразование цвета *Standard* вместо AgX.

### Исправления
- Масштабирование в Blender больше не ломает размер детали в Studio: размер считается по
  фактическим габаритам объекта. Раньше после «Apply Scale» (Ctrl+A) деталь в Studio
  превращалась в маленький кубик.
- Общие меши деталей защищены от изменения в Blender: «Apply Scale» на одной детали больше
  не искажает все остальные, а изменённые меши восстанавливаются при следующей синхронизации.
- Ctrl+Z и открытие `.blend` при работающей связи больше не создают дубликаты объектов.
  После открытия файла Studio сама присылает сцену заново.
- Надписи на кириллице больше не получают одну и ту же текстуру на всех табличках.
- Синхронизация больше не зависает навсегда после ошибки в полной синхронизации.
- Одна «битая» деталь больше не срывает отправку всей сцены.
- Порт сервера можно сменить: атрибут `LiveLinkPort` у Workspace.
- ID ассетов из URL вида `.../v1/asset?id=123` распознаются правильно.
- Режим Selection больше не замедляется со временем.
- Сервер устойчив к некорректным запросам (неверный `Content-Length`, зависшие соединения).
- «Boost Playback FPS» удаляет только неиспользуемые материалы Roblox, а не все данные `.blend`.
- Длинные имена материалов больше не плодят копии в Blender 4.x.
- Текстуры сохраняются на диск атомарно.

### Плагин Studio
- Устанавливать как `RobloxLiveLink.lua`: файлы `.luau` Studio из папки Plugins не загружает.
- Собственные иконки кнопок, подписи кнопок.
- Убраны кнопки Import Mode и Send Selected. Осталось: Live Sync, Sync Mode, Separate.

### Известные проблемы
- Union-детали (UnionOperation) приходят коробкой по габаритам.
- Terrain не переносится.
- Часть ассетов Roblox отдаёт только после входа в аккаунт (ошибка 401). Такие меши приходят
  коробками, картинки подтягиваются через публичные превью (до 420×420).
- Освещение и постэффекты (Bloom, ColorCorrection, Atmosphere, тени) не переносятся. В режиме
  Material Preview теней нет, поэтому, например, потолок тоннеля светлее, чем в Roblox.
- Процедурные материалы похожи на материалы Roblox, но не совпадают с ними один в один.
- Полупрозрачные детали в Material Preview выглядят зернистыми (dithering EEVEE).
- Декали, Texture и SurfaceGui по граням рисуются только на блоках. На шарах, цилиндрах, клиньях
  и MeshPart — одна текстура на деталь.
- Неудачная загрузка ассета повторяется только после перезапуска Blender.
- Значок на SpawnLocation (`rbxasset://textures/SpawnLocation.png`) в новых версиях Studio не лежит
  на диске, поэтому в чистой установке он не отображается.
