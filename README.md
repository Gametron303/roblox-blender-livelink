# Roblox Studio ↔ Blender Live Link — 1.3.2-beta

> ⚠️ **Бета-версия, ещё тестируется.** Возможны ошибки, а поведение может измениться
> в следующих версиях. Перед работой сохраняйте плейс и `.blend`. Об ошибках пишите
> (лучше со скриншотом и текстом из Output Studio и консоли Blender) в
> [Issues](https://github.com/Gametron303/roblox-blender-livelink/issues).
> Список изменений и известных проблем — в [CHANGELOG.md](CHANGELOG.md).

*English version: [README.en.md](README.en.md).*

Живая связка Roblox Studio и Blender. Детали, модели, меши, текстуры и надписи из Studio
появляются в Blender и обновляются на лету. Перемещение, поворот и масштаб из Blender
возвращаются обратно в Studio.

Состоит из двух частей:

| Часть | Файл релиза | Что делает |
|---|---|---|
| Расширение Blender | `roblox_blender_livelink-1.3.2-beta-<платформа>.zip` | Локальный сервер на `127.0.0.1:28888`, строит сцену в Blender |
| Плагин Studio | [Creator Store](https://create.roblox.com/store/asset/113147868123756) | Отправляет сцену в Blender и принимает изменения обратно |

Поддерживаются **Windows и macOS** (Roblox Studio существует только там) и **Blender 4.2 и новее**.

---

## 1. Установка

### Blender (расширение, 4.2 и новее)

1. Если раньше стояла старая версия (аддон «Roblox Studio Live Link» в **Add-ons**), отключите
   и удалите её. Иначе обе версии будут бороться за порт 28888. Скачанные ею текстуры и меши
   новая версия при первом включении перенесёт к себе сама.
2. Возьмите zip для своей системы:
   - Windows — `roblox_blender_livelink-1.3.2-beta-windows_x64.zip`
   - Mac на Apple Silicon (M1–M4) — `...-macos_arm64.zip`
   - Mac на Intel — `...-macos_x64.zip`
3. Перетащите zip в окно Blender **или** откройте **Edit → Preferences → Get Extensions → ⌄ →
   Install from Disk…** и выберите файл.
4. Включите **Edit → Preferences → System → Network → Allow Online Access**: без этого меши
   и текстуры Roblox не скачиваются (расширение покажет предупреждение в панели).

Pillow (для надписей и SurfaceGui) уже лежит внутри расширения, ставить ничего не нужно.

### Roblox Studio

Плагин ставится из Creator Store: откройте [Blender Live Link (Beta)](https://create.roblox.com/store/asset/113147868123756), нажмите
**Get** и затем установите плагин в Studio. Обновления будут приходить сами.

После установки:
1. Перезапустите Studio.
2. На вкладке **Plugins** появится панель **Blender Bridge** с тремя кнопками, а в Output строка
   `[Roblox Live Link] Plugin ready (v1.3.2-beta)...`.
3. При первом подключении Studio спросит разрешение на HTTP-запросы к `127.0.0.1`. Нажмите **Allow**.

## 2. Быстрый старт

1. **Blender:** в 3D-вьюпорте нажмите `N` → вкладка **Roblox** → **Start Server**.
   Статус станет `ACTIVE (Port 28888)`.
2. **Studio:** выделите в Explorer или во вьюпорте то, что нужно перенести (деталь, модель, папку).
3. Нажмите **Live Sync**. В Output появится `Connected to Blender Server!` и
   `Scene sync completed: N objects sent.`
4. Объекты появятся в Blender в коллекции `Roblox_LiveLink`. Всё, что вы дальше выделяете в Studio,
   тоже добавляется в синхронизацию.

Чтобы остановить синхронизацию, ещё раз нажмите **Live Sync** в Studio или **Stop Server** в Blender.

## 3. Кнопки в Studio (панель Blender Bridge)

### 🔄 Live Sync
Включает и выключает синхронизацию. Пока она включена, изменения в Studio уходят в Blender
примерно 5 раз в секунду, а изменения из Blender возвращаются в Studio.

### 🖱 Sync Mode
Определяет, *что* синхронизируется. Каждый клик переключает режим по кругу, и иконка меняется:

| Иконка | Режим | Что попадает в Blender |
|---|---|---|
| Курсор | **Selection** (по умолчанию) | Всё, что вы выделяли с момента включения Live Sync. Снятие выделения объект из Blender **не** убирает. |
| Папка | **BlenderSync** | Только содержимое папки (или модели) `Workspace.BlenderSync`. Если такой папки нет, не синхронизируется ничего. |
| Глобус | **Workspace** | Весь Workspace. На больших плейсах (тысячи деталей) это тяжело, лучше выбрать Selection или BlenderSync. |

В режимах BlenderSync и Workspace при старте из Blender удаляется всё, чего больше нет в Studio.
В режиме Selection объекты из прошлых сессий остаются.

### ✂ Separate
По умолчанию каждая модель (дом, дерево, машина) приходит в Blender **одним объектом-мешем**:
так быстрее, и сцена не захламляется тысячами деталей. Кнопка **Separate** переключает
выделенные модели или детали в режим «отдельные детали» и обратно. Это нужно, если вы хотите
двигать или масштабировать в Blender отдельные части модели.

- Персонажи с `Humanoid` всегда приходят отдельными деталями.
- Кнопка ставит атрибут `LiveLink_SeparateParts` прямо на объект в плейсе. В Team Create его
  увидят все, и он сохранится вместе с плейсом.

## 4. Панель в Blender (N → Roblox)

| Блок | Что там |
|---|---|
| **Status** | Start/Stop Server и порт (по умолчанию `28888`) |
| **Viewport & Playback FPS** | **Boost Playback FPS** облегчает вьюпорт для плавного воспроизведения. **Show Textures & Colors** включает режим Material Preview. **Match Roblox Colors** (включено по умолчанию) ставит преобразование цвета *Standard* вместо AgX: AgX высветляет и обесцвечивает цвета деталей по сравнению с Roblox. Ниже кнопки скрытия и показа коллекций: на тяжёлых сценах скрывайте ненужные, чтобы поднять FPS. |
| **Sync Progress & Stats** | Прогресс приёма сцены и число объектов |
| **CSG / Slabs** | Показать или скрыть коллекцию `Roblox_CSG_Operations` (Union-детали) |
| **Add Primitive (to Studio)** | Block / Sphere / Cylinder / Wedge: создаёт деталь в Blender **и** в Studio, в папке `Primitives` или в активной коллекции |
| **Materials & UV Scale** | Масштаб рисунка материалов (кирпич, доски, трава…). После изменения нажмите **Apply Texture Scale**. |
| **Scene Management** | **Clear Synced Objects** удаляет всё синхронизированное из Blender (в Studio ничего не трогает). **Reload Addon Code** перечитывает код аддона с диска. |

## 5. Редактирование из Blender → Studio

Синхронизация двусторонняя, но несимметричная:

| Направление | Что передаётся |
|---|---|
| Studio → Blender | Всё: детали, модели, меши, материалы, цвета, прозрачность, декали, текстуры, надписи, появление и удаление объектов |
| Blender → Studio | Только перемещение, поворот и масштаб, перенос между коллекциями (папками) и новые детали из **Add Primitive** |

Из Blender в Studio **не** передаются: удаление, цвет, материал и текстуры, правка геометрии
(Edit Mode, модификаторы) и обычные объекты Blender, созданные не через Add Primitive.

1. Выделите объект в Blender и подвиньте, поверните или отмасштабируйте его (`G` / `R` / `S`).
2. Через долю секунды деталь в Studio окажется там же. Всё изменение из Blender отменяется
   **одним Ctrl+Z в Studio** (шаг «Blender Live Link»).

Что важно знать:
- Отслеживаются только **выделенные** в Blender объекты.
- **Объединённую модель** можно только двигать и поворачивать целиком. Чтобы менять отдельные
  части, включите для неё **Separate** в Studio.
- Масштаб отдельной детали превращается в её `Size` в Studio.
- Перенос объекта в другую коллекцию Blender переносит деталь в соответствующую папку в Studio.
- **Удаление в Blender не удаляет деталь в Studio.** Удаление в Studio убирает объект из Blender.
- Копия через `Shift+D` в Blender становится обычным объектом, не связанным с Studio.
- Ctrl+Z в Blender работает нормально: отменённое перемещение выделенного объекта тоже уйдёт в Studio.

## 6. Что переносится

| В Studio | В Blender |
|---|---|
| Part (Block, Ball, Cylinder), WedgePart | Примитив нужной формы и размера |
| MeshPart, SpecialMesh (FileMesh) | Настоящая геометрия, скачивается с Roblox и кэшируется |
| Материалы Roblox (Grass, Wood, Brick, Concrete, Metal, Slate, Sand… — все) | Процедурный материал: рисунок строится узлами шейдера, цвет детали задаёт итоговый цвет. Похоже на Roblox, но не один в один. |
| MaterialVariant (на детали или как переопределение материала в MaterialService) | Свои ColorMap / NormalMap / RoughnessMap / MetalnessMap с тайлингом по StudsPerTile |
| Neon | Светящийся материал |
| Decal (любое количество, на любых гранях, по ZIndex) | Картинка на своей грани блока, с цветом Color3 и прозрачностью |
| Texture | Тайловая текстура на своей грани (StudsPerTile, Offset, Color3, прозрачность) |
| SurfaceGui | Отрисовывается целиком: Frame, TextLabel, ImageLabel, UIStroke, UICorner, TextScaled, перенос строк, ImageRect (спрайт-листы). Шрифты берутся из Studio, кириллица поддерживается. |
| SurfaceAppearance, MaterialVariant, текстура MeshPart | Картинка, скачивается с Roblox |
| Shirt / Pants на R15-персонаже | Одежда, натянутая на детали тела |
| Папки и модели | Вложенные коллекции |

**Ограничения:**
- **UnionOperation** приходит коробкой по габаритам: плагин не может прочитать геометрию Union.
- **Terrain** не переносится. **CornerWedge, Truss** и подобные приходят коробками.
- Декали, Texture и SurfaceGui рисуются по граням только на деталях-**блоках** (Part Block,
  SpawnLocation). На шарах, цилиндрах, клиньях и MeshPart остаётся одна текстура на всю деталь.
- Для первой загрузки мешей и текстур нужен интернет. Если загрузка не удалась, повтор будет
  только после перезапуска Blender.
- Освещение и постэффекты Roblox (Bloom, ColorCorrection, Atmosphere, тени солнца) не переносятся,
  поэтому картинка в Blender отличается от Studio по свету, а не по материалам.
- **Часть ассетов Roblox отдаёт только после входа в аккаунт** (ошибка 401). Такие меши не
  скачиваются и приходят коробкой. Картинки обычно подтягиваются через публичные превью Roblox
  (до 420×420). Прочитать их через плагин тоже нельзя: Studio разрешает это только для ваших
  собственных ассетов.
- В режиме Selection клик по детали внутри большой модели отправляет в Blender всю модель.

## 7. Тонкая настройка через атрибуты Studio

| Атрибут | Где | Значение |
|---|---|---|
| `LiveLinkIgnore = true` | на детали | Деталь не синхронизируется |
| `LiveLink_SeparateParts = true` | на модели или детали | То же, что кнопка Separate |
| `LiveLinkPort = 28889` | на Workspace | Нужен, если в Blender выставлен порт, отличный от 28888 |
| `LiveLinkSync = true/false` | на Workspace | Включить или выключить синхронизацию из скрипта или командной строки |
| `LiveLinkId` | ставится автоматически | Связь детали с объектом в Blender. Не копируйте и не меняйте вручную. |

## 8. Если что-то не работает

| Симптом | Что сделать |
|---|---|
| Нет панели **Blender Bridge** в Studio | Проверьте в **Plugins → Manage Plugins**, что плагин Blender Live Link установлен и включён, и перезапустите Studio. Посмотрите Output на ошибки. |
| `Blender server unreachable. Click 'Start Server' in Blender.` | В Blender не запущен сервер (N → Roblox → Start Server), или порты в Blender и Studio не совпадают. |
| В Blender пусто, хотя Live Sync включён | В режиме Selection нужно что-то выделить. В режиме BlenderSync должна существовать папка `Workspace.BlenderSync`. |
| `Failed to bind port 28888` в Blender | Live Link уже запущен в другом окне Blender. Остановите его там или смените порт (и выставьте `LiveLinkPort` в Studio). |
| Меш показан коробкой, текстуры нет | Ещё скачивается: объект обновится сам через пару секунд. Приватные ассеты скачать нельзя. |
| В Blender остались объекты, которых уже нет в Studio | В режиме Selection старые объекты не удаляются. Нажмите **Clear Synced Objects** и включите Live Sync заново. |
| Studio тормозит на большом плейсе | Не используйте режим Workspace. Выделяйте только нужное или соберите это в папку `BlenderSync`. |

## Структура проекта

```
blender_addon/              исходники расширения Blender
  blender_manifest.toml     метаданные расширения (версия, лицензия, платформы, wheels)
  __init__.py               панель и кнопки
  paths.py                  где лежат файлы: текстуры материалов и пользовательский кэш
  server.py                 HTTP-сервер (Studio ↔ Blender)
  sync_manager.py           построение сцены, материалы, обратная синхронизация
  mesh_loader.py            чтение форматов .mesh Roblox (v1–v7)
  surfaces.py               Decal / Texture / SurfaceGui по граням: отрисовка GUI, шрифты, запекание
  procedural.py             процедурные материалы Roblox (узлы шейдера, без картинок)
  material_cache/           локальный кэш скачанных ассетов при запуске из исходников (в релиз не идёт)
  wheels/                   Pillow для Windows и macOS (Python 3.11 и 3.13)
roblox_plugin/
  RobloxLiveLink.server.luau   плагин Studio
  icons/                       исходники иконок кнопок (загружены на Roblox как ассеты)
tools/build_release.py      сборка релиза через `blender --command extension build`
release/<версия>/           готовые zip для каждой платформы, плагин, README, CHANGELOG
```

Скачанные текстуры и меши хранятся в пользовательской папке расширения
(`.../extensions/.user/user_default/roblox_blender_livelink/cache`) и в релиз не попадают.

Сборка релиза:

```bash
python tools/build_release.py --blender "C:/Program Files/Blender Foundation/Blender 5.2/blender.exe"
```

## Текстуры и авторские права

Расширение **не содержит текстур Roblox и других чужих изображений**. Рисунок всех встроенных
материалов (кирпич, дерево, трава, бетон, камень и т. д.) **генерируется процедурно** узлами
шейдера Blender прямо в момент синхронизации, чтобы не нарушать ничьих авторских прав. Поэтому
материалы похожи на материалы Roblox, но не совпадают с ними один в один.

Картинки, которые используются в вашей собственной игре (декали, текстуры, MaterialVariant,
надписи), скачиваются с серверов Roblox на ваш компьютер только во время работы и хранятся
в локальном кэше. В пакет расширения они не входят.
